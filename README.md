# Machine-Learning

Machine learning projects, grouped by level.

## Basic

| Project | What it does |
|---|---|
| [Per Capita Income](Basic/Per%20Capita%20Income) | Linear regression that predicts Canada's per capita income from the year |
| [Salary Offer](Basic/Salary%20Offer) | Linear regression that predicts a candidate's salary offer from their experience, test score and interview score |

## Intermediate

| Project | What it does |
|---|---|
| [Life Expectancy Predictor](Intermediate/Life%20Expectancy%20Predictor) | Predicts a country's life expectancy from health and economic data, comparing linear regression with random forest. Includes a report and a presentation |

## Advance

| Project | What it does |
|---|---|
| [Web-Scraper](Advance/Web-Scraper) | A Scrapy crawler that builds a Bangla and English news dataset for training models, from Bangladeshi and international news sites |
